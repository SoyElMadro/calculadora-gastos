# 💸 Calculadora de Gastos

Una aplicación web simple para registrar y controlar gastos personales de forma rápida, visual e intuitiva.

## ✨ Características

- Agregar y eliminar gastos
- Cálculo automático de totales
- Interfaz moderna y responsive
- Organización clara de los gastos
- Funciona directamente desde el navegador

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript Vanilla

## 🚀 Cómo usar

1. Clona este repositorio:

```bash
git clone https://github.com/SoyElMadro/calculadora-gastos.git
```

2. Abre el proyecto en tu editor de código.
3. Ejecuta el index.html en tu navegador.
